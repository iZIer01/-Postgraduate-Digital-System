Installation
------------
1. Install system dependencies:
   - PHP 8.2+
   - Composer 2.x
   - Node.js 18.x+ and npm
   - MySQL / MariaDB or another supported database server

2. Open the active Laravel project root:
   cd "Postgraduate-Digital-System\supervisor"

3. Install PHP dependencies:
   composer install

4. Install JavaScript dependencies:
   npm install

5. Copy the environment example file:
   copy .env.example .env

6. Generate the application key:
   php artisan key:generate

7. Update database settings in `.env`:
   DB_CONNECTION=mysql
   DB_HOST=127.0.0.1
   DB_PORT=3306
   DB_DATABASE=supervisor
   DB_USERNAME=your_db_user
   DB_PASSWORD=your_db_password

8. Run database migrations:
   php artisan migrate
   php artisan db:seed

Running the application
-----------------------
- Start the dev environment:
  npm run dev

- Or run only Laravel server:
  php artisan serve

- Visit in browser:
  http://127.0.0.1:8000

Additional commands
-------------------
- Build production assets:
  npm run build

- Run tests:
  composer test

- Run the setup script:
  composer run setup

Notes
-----
- If you see duplicate `package.json` / `package-lock.json` files, use the nested project root at `Postgraduate-Digital-System\supervisor`.
- Ensure `.env` is configured correctly before migrating and serving.
