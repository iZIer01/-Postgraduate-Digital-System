Project Requirements
====================

Core stack
----------
- PHP: ^8.2
- Laravel Framework: ^12.0
- Node.js: 18.x or later recommended
- npm: 10.x or later (bundled with Node)
- Composer: 2.x
- Database: MySQL / MariaDB (or other supported Laravel database)

Installation
------------
1. Install system dependencies:
   - PHP 8.2+
   - Composer 2.x
   - Node.js 18.x+ and npm
   - MySQL / MariaDB or another supported database server

2. Navigate to the project root:
   cd supervisor

3. Install PHP dependencies:
   composer install

4. Install JavaScript dependencies:
   npm install

5. Copy the environment example file:
   copy .env.example .env

6. Generate the application key:
   php artisan key:generate

7. Configure database connection in `.env`:
   - DB_CONNECTION=mysql
   - DB_HOST=127.0.0.1
   - DB_PORT=3306
   - DB_DATABASE=supervisor
   - DB_USERNAME=your_db_user
   - DB_PASSWORD=your_db_password

8. Run database migrations:
   php artisan migrate

Running the application
-----------------------
- Start Vite and the Laravel development server:
  npm run dev

- Or manually start the Laravel server:
  php artisan serve

- Open the application in a browser at:
  http://127.0.0.1:8000

Additional useful commands
--------------------------
- Build production assets:
  npm run build

- Run tests:
  composer test

- Run the project setup script (installs dependencies, creates `.env`, generates key, migrates, and builds assets):
  composer run setup
